Clock discipline

Six-hour plan

If a task is not on this page, it does not start until MVP is green. Times assume one strong implementer or two people who do not collide on the same files.

T+0 → T+6:00 Cut bonus first demo_flow.sh is the heartbeat

Pre-clock (if you have 20 minutes before T+0)

  1. Install Foundry: curl -L https://foundry.paradigm.xyz | bash && foundryup
  2. gh auth status. Then run the bootstrap clone block in REPOS.html.
  3. Create a fresh throwaway key. Fund Sepolia and Amoy from public faucets. Never reuse a mainnet key.
  4. Copy .env.example → .env.
  5. Skim CLAUDE.html and SCHEMA.html.

Hour 0 — Contracts and layout (T+0:00–1:00)

  • foundry init inside contracts/. Remap OpenZeppelin from the cloned repo or forge install OpenZeppelin/openzeppelin-contracts.
  • Write ClaimSource.sol + IdentityState.sol + tests: post, revoke, claimId stability, commit idempotency, latest().
  • forge test -vv green before deploy.
  • Deploy script takes chain id. Reject 1 and 137.
  • Deploy ClaimSource to Sepolia and Amoy, IdentityState to Sepolia. Save addresses in .env.
  • Cut line: if deploy fails, keep Anvil for tests but do not stop trying public testnets — the deliverable needs a real tx.

Hour 1 — Ingest + schemas (T+1:00–2:00)

  • Pydantic models from SCHEMA.html.
  • Log watcher with cursors on disk data/cursors.json (local file is not a hosted DB).
  • Backfill last 2k blocks on each chain.
  • Script to post fixture claims A and B.
  • Print decoded events. Do not start the LLM yet if this is late.

Hour 2 — Dataset + model (T+2:00–3:00)

  • Generate data/claims_train.jsonl (≥ 800). Document the label function in a header comment.
  • Train HistGradientBoosting. Persist joblib. Write data/metrics.json.
  • If accuracy < 75%, add signal features (revoked, expired, issuer prior) — you under-noised the labels or over-noised the features. Fix data, do not stack networks.
  • Unit test: predict on a revoked+expired row → p < 0.4.

Hour 3 — Fusion + writer + API (T+3:00–4:00)

  • Implement Beta mapping and cumulative / averaging fusion. Test against the numeric examples in MATH.html.
  • Writer: compute commitId, send tx, handle revert-as-success.
  • FastAPI: health, GET identity, GET history. In-memory overlay.
  • Wire ingest → score → fuse → overlay → writer.
  • scripts/demo_flow.sh must work by T+4:00 even with rules-based normalize.

Hour 4 — Gen-AI extract + explain + revoke (T+4:00–5:00)

  • Instructor/DSPy extract prompt. Timeout + fallback.
  • SHAP values on the scored vector.
  • Explanation prompt. Cache on disk keyed by commitId.
  • Revocation path (B-01). This is more impressive than a pretty UI.
  • verify_hash.py green.

Hour 5 — Dashboard, video, hardening (T+5:00–6:00)

  • 0–25 min: dashboard if and only if API is solid. DESIGN.html tokens. Browser-verify.
  • 25–40 min: load test GET (hey or wrk). Fix obvious n+1 RPC.
  • 40–55 min: record the 3-minute video. Script below. One take. Do not polish slides.
  • Last 5 min: README with addresses, tx hash, curl, accuracy, dead-testnet note.
