Skills

Each skill is a closed procedure. Run them in PLAN.html order. Do not start a skill whose inputs are missing.

Skill: Foundry contracts

  1. Init and install as INTEGRATION.html.
  2. Write the two contracts from ARCHITECTURE.html. No proxies.
  3. Tests: post+revoke, claimId stability across calls, only issuer revokes, only operator commits, duplicate commitId reverts, latest updates, scoreBps 10001 reverts.
  4. forge test. Then deploy. Then cast logs on a manual post.

Skill: Hardhat fallback

Only if foundryup fails. Clone NomicFoundation/hardhat for docs, then:

npm init -y
npm i -D hardhat @nomicfoundation/hardhat-toolbox
npx hardhat init

Same Solidity, same addresses in .env. Do not keep both toolchains.

Skill: Ingest

  1. Build contract ABI JSON from forge inspect ClaimSource abi.
  2. web3.py create_filter from fromBlock=cursors[chain].
  3. On log: decode, write NormalizedClaim skeleton, persist cursor only after successful decode.
  4. Reorg: if parent hash mismatches, subtract 12 / 64 blocks and rescan.

Skill: Synthetic dataset

  1. Sample issuer class ∈ {honest, noisy, hostile} with Beta seeds from MATH.html.
  2. Sample revoked, expired, conflict_count from independent Bernoullis (p=0.15, 0.2, 0.25).
  3. Hidden reliability y = 1 if issuer honest and not revoked and not expired and conflict_count<2, else mix in noise so the model must use several features (flip 12% of labels).
  4. Write 800+ rows. Split 80/20 with seed 7. Print accuracy, F1, Brier.

Skill: Fusion library

  1. Implement to_opinion(r,s,a=0.5,W=2), expect(ω), cumulative(a,b), average(a,b), discount(trust, ω).
  2. Port the worked A⊕B numbers. Assert abs(err)<1e-4.
  3. Zero-uncertainty disagreement branch.
  4. Deterministic sort by claimId before reduce.
