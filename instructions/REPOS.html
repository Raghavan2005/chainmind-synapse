Every URL below was resolved with gh repo view owner/name on 2026-08-23. Several well-known names have moved. Use the resolved owner/name, not the folklore name. Stars are a snapshot, not a ranking.

gh CLI rules

# auth once
gh auth status || gh auth login

# always probe before telling a human to clone
gh repo view OWNER/NAME --json nameWithOwner,url,description,stargazerCount,isArchived,defaultBranchRef

# clone into vendor-ref/ (reference only — do not vendor unless needed)
mkdir -p vendor-ref
cd vendor-ref
gh repo clone OWNER/NAME

# shallow + one branch when you only need to read
gh repo clone OWNER/NAME -- --depth 1 --single-branch

# pin a tag
gh repo clone OWNER/NAME
git -C NAME fetch --tags
git -C NAME checkout TAG

gh repo clone uses HTTPS or SSH according to your gh config. Prefer HTTPS on machines without SSH keys. Do not git clone a guessed URL if gh repo view fails.
