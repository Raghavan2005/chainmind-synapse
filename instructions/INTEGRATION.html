Integration instructions

This is the only page that tells you how the verified repos become one process tree. Copy commands. Do not invent extra platforms.

Prerequisites

  • macOS/Linux, git, gh authenticated, Python 3.11+, Node 20+ (dashboard only), curl.
  • Foundry: curl -L https://foundry.paradigm.xyz | bash then foundryup. Confirm forge --version.
  • Throwaway key with Sepolia ETH. Bridge to each watched L2 with bash scripts/bridge_sepolia_to_l2.sh <unichain|base|op|ink|mode|soneium>. Never a mainnet L1StandardBridge.

LLM wiring (LiteLLM + Instructor)

export LLM_BASE_URL=https://api.openai.com/v1   # any OpenAI-compatible server
export LLM_API_KEY=...
export LLM_MODEL=gpt-4.1-mini

Operator env is the default for live ingest extract. Frontend BYOK is browser localStorage + POST /v1/llm/test and POST /v1/identity/{subject}/explain body {apiKey, baseUrl, model}. Never persist keys server-side.

    addr = addr.lower()
    if chain_id == 11155111:
        return f"did:ethr:sepolia:{addr}"
    if chain_id in {1301, 84532, 11155420, 763373, 919, 1946}:

Operate after deploy

  • Processes. Ingest+writer owns the private key. API is read-only. Do not run two writers. Overlay: data/overlay.json via os.replace.
  • Health. Probe GET /v1/health every 15s. If degraded is true, do not post new demo claims until the lag is explained.
  • Logs. Keep stdout. Event names are in ARCHITECTURE.html (ingest.head, commit.mined, fuse.conflict, …).
  • Replay. POST /v1/replay/{subject} with the bearer from env rebuilds overlay from logs. Use this after a crash. The chain is the record.
  • Incidents. RPC 429 → backoff, second URL in .env. Unichain down → serve Sepolia + last Unichain snapshot, flag degradedChains; run scripts/emergency_anvil_source.sh for a live local fallback instead (health reports emergencySource). LLM down → rules + template explanation. Model file missing → refuse API start.
  • Keys. Demo: throwaway faucet account. Never a mainnet key. Never commit .env.
  • Hosted UI. Vercel serves the dashboard. The API stays on this machine (or Compose) unless a human accepted AWS compute in DEVOPS.html. Paste VITE_API_BASE / the BYOK API-base field. Do not put operator keys on Vercel.

You are integrated when

  1. GET /v1/health shows both heads moving and modelAccuracy > 0.75.
  2. Two explorers show ClaimPosted.
  3. Sepolia explorer shows StateCommitted.
  4. verify_hash.py exits 0.
  5. Killing uvicorn and running replay reconstructs the same latest hash.
