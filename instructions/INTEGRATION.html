Integration instructions

This is the only page that tells you how the verified repos become one process tree. Copy commands. Do not invent extra platforms.

Prerequisites

  • macOS/Linux, git, gh authenticated, Python 3.11+, Node 20+ (dashboard only), curl.
  • Foundry: curl -L https://foundry.paradigm.xyz | bash then foundryup. Confirm forge --version.
  • Throwaway key with Sepolia ETH and Amoy POL.

Run the brain

source .venv/bin/activate
python -m services.score.train          # writes data/model.joblib + data/metrics.json
uvicorn services.api.main:app --host 0.0.0.0 --port 8000
# other terminal
python -m services.ingest.watch

Ingest process owns the writer. API process is read-only plus health. Share overlay via a local JSON file data/overlay.json with atomic replace (os.replace). That file is a cache, not the source of truth.

Instructor:

from instructor import from_openai
from openai import OpenAI
from services.normalize.schema import NormalizedClaim

client = from_openai(OpenAI(base_url=os.environ["LLM_BASE_URL"], api_key=os.environ["LLM_API_KEY"]))
claim = client.chat.completions.create(
    model=os.environ["LLM_MODEL"],
    response_model=NormalizedClaim,
    temperature=0,
    messages=[...],  # PROMPTS.html
)

DSPy alternative: one dspy.Signature per prompt file. Do not enable DSPy teleprompt / compile that trains weights if that counts as fine-tuning in your org’s reading of the PRD. Use zero-shot signatures only.

SHAP wiring

import shap, joblib
model = joblib.load("data/model.joblib")
explainer = shap.TreeExplainer(model)
sv = explainer.shap_values(x_row)  # x_row shape (1, d)

If the model is logistic, shap.LinearExplainer with the train background (≤ 100 rows).

did:ethr without a full SSI runtime

def did_ethr(chain: str, addr: str) -> str:
    addr = addr.lower()
    if chain == "sepolia":
        return f"did:ethr:sepolia:{addr}"
    if chain == "amoy":
        return f"did:ethr:eip155:80002:{addr}"
    raise ValueError(chain)

Read uport-project/ethr-did README for the network-name table. Optional: verify a JWT-VC with decentralized-identity/did-jwt-vc in a Node one-off. The Python path can accept unsigned JSON for the hackathon if you say so in the video — still emit VC-shaped fields.
