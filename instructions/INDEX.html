What this product is

Users hold credentials on multiple chains. Those claims expire, get revoked, and sometimes contradict each other. A service on chain B cannot tell whether a claim from chain A is still true. ChainMind Synapse is the missing reconciliation layer: real-time ingest, Gen-AI signal extraction via prompt orchestration (not fine-tuning), an sklearn/Hugging Face credibility model, a fused identity state, an auditable on-chain commitment, and a REST API that returns sources plus scores in under 500 ms.

Existing products score wallet behavior or credit (Nomis, RubyScore, Cred), social credibility (Ethos, UTU), or humanity / Sybil risk (Trusta.AI, Human Passport). DID/VC is a claim format. Chainlink ACE is a credential registry and policy engine. ERC-8004 is a draft agent-identity ERC. None of them reconcile conflicting credential claims with an explainable, tamper-proof verdict. That remaining conjunction is the product. See RESEARCH.html and the repo file research-existing-solutions.md.

Hard constraints (do not negotiate)

Clock: 6 hours to a working testnet demo.

Chains: at least two. PRD names Goerli and Mumbai; both were sunset in April 2024. First substitute was Sepolia + Amoy; Amoy POL became unobtainable. Human override 2026-08-23: Sepolia (11155111) and Unichain Sepolia (1301) remain the FR-01 pair. Extra ingest sources (same day, SepETH via CLI): Base Sepolia 84532, OP Sepolia 11155420, Ink Sepolia 763373, Mode Sepolia 919, Soneium Minato 1946. Say the pair out loud; the extras are optional watched L2s, not a silent pair swap.

No identity providers, no centralized database as source of truth. Process in memory / local files. The ledger is the record.

Gen-AI = prompt orchestration only. Instructor over LiteLLM (or DSPy / Compozy / raw structured prompts). No LoRA, no SFT, no “we fine-tuned a judge.” No raw OpenAI client as the product router.

ML = existing libraries. scikit-learn first. Hugging Face only if it still fits the clock. Train on synthetic + historically labeled claims you generate.

No pre-built identity reconciliation product. Do not wrap Trusta.AI, Nomis, RubyScore, Ethos, Cred Protocol, UTU Trust, or Gitcoin Passport (passportxyz/passport) and call it done. W3C DID/VC is a format, not a reconciliation engine — using the format is required-adjacent and allowed.

Canonical stack (do not bikeshed)

On-chain

Foundry + Solidity + OpenZeppelin. ClaimSource on every watched chain (Sepolia, Unichain Sepolia, and the extra Superchain L2s in services/common/chains.py). IdentityState on one settlement chain (Sepolia). Hash-only commitments. Idempotent writes.

Off-chain brain

Python 3.12. FastAPI + uvicorn. web3.py or viem (Node ingest sidecar is fine). sklearn HistGradientBoosting. Instructor over LiteLLM for extraction and explanation prose. SHAP + template fallback if no key.

Identity format

W3C VC Data Model 2.0 as the claim envelope. did:ethr as the subject/issuer identifier. Bitstring Status List semantics for revocation; implement a simple on-chain revoked bit if the clock is tight.

Dashboard (bonus)

Vite + React. Read-only. Polls the REST API. Shows claim timeline, conflicts, SHAP bars, and the on-chain tx hash. Design tokens in DESIGN.html.

Math in one breath

Each claim becomes a subjective-logic opinion (belief, disbelief, uncertainty, base-rate) mapped from a Beta reputation posterior over issuer history, plus an sklearn probability that the claim is currently credible. Independent-looking evidence is fused with Jøsang cumulative fusion; dependent echoes use averaging fusion. High conflict triggers source-trust revision (Jøsang 2017). The fused expectation is the confidence score written on-chain in basis points. SHAP attributes the sklearn score; the Gen-AI layer narrates both SHAP and the fusion residual. Full treatment: MATH.html.
