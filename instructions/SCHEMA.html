Schemas

If two teammates (or two agents) disagree, this page wins. Field names are stable. Do not camelCase one side and snake_case the other — JSON is camelCase, Python models use aliases, Solidity is the interfaces in ARCHITECTURE.html.

Topic identifiers

Topics are bytes32 on-chain = keccak256(ascii) of a dotted name. Demo names:

  • kyc.adult — subject is over 18 / eligible.
  • kyc.active — KYC currently active (revocation matters).
  • residency.eu — optional second topic if you need a non-conflict control.

Feature vector (order is law)

  1. issuer_prior — Beta expectation \(E[p_I]\)
  2. issuer_volume — log1p(claim count of issuer)
  3. hours_to_expiry — can be negative
  4. expired — 0/1
  5. revoked — 0/1
  6. claim_age_hours
  7. confirmations_norm — min(conf,32)/32
  8. signature_valid — 0/1
  9. conflict_count — other live claims on same subject+topic with opposite polarity
  10. chain_is_settlement — 1 if Sepolia (hackathon prior: settlement chain slightly more watched)
  11. polarity — +1/−1
  12. evidence_len_norm — min(len(rawText), 2000)/2000

Optional 13: text_emb_0… only if MiniLM is on. Then bump modelVersion.
