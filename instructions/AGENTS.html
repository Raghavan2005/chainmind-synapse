Agents

Two layers. Inside the product: small, boring, structured Gen-AI clerks. Around the repo: Cursor / Claude / Compozy workers that implement PLAN.html. Do not confuse them. Coding agents load repo-root AGENTS.md / CLAUDE.md, then work from this instructions/ HTML pack.

Only Extractor and Explainer are “Gen-AI agents.” Everything else is deterministic code. That is how we stay under 500 ms on GET and honest on the score.

Loop: Watcher → Extractor → Featurizer → Scorer → Fuser → (Writer ∥ Explainer) → API overlay. Mutex per subject in Fuser/Writer.

Capabilities (keep few)

If you add function-calling, these are the only tools:

  • read_event(chainId, txHash, logIndex)
  • fetch_evidence(uri) — allowlist, size cap 64 KiB, no private IPs
  • get_issuer_prior(address)

No google_search. No score_with_trusta. No write_chain from the LLM.
