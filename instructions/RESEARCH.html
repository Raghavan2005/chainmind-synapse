Recommended SOTA stack for this exact PRD

Must run

Beta issuer prior + SL cumulative/average fusion + conflict penalty + sklearn GBM + SHAP + structured extract/explain prompts + hash-anchored IdentityState + two-chain event ingest.

Should mention

Bitstring Status List, hash-only VC anchoring (2025), CRAVE dual perspective, TrustJudge caution, ERC-8004 as agent cousin, EigenTrust as graph upgrade, zk revocation as privacy upgrade.

Must not run

Fine-tuned judges, Passport/Trusta APIs, CCIP/LayerZero identity bridges, ION/Ceramic/ACA-Py as runtime, STARK circuits, Dirichlet multi-class reputation.

If the clock is kind

EIP-712 signed claims, MiniLM text embedding feature, DS engine flag, tiny issuer EigenTrust, Vite dashboard, IPFS preimage CID in the commit event.
