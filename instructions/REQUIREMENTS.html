Required fixtures

  • DEMO_SUBJECT — one address used in the video.

Testing and validation strategy

If it is not in this list, it is not a release gate. Run in this order so a red Forge test never hides behind a pretty curl.

LayerCommand / artifactWhat it proves
Contractsforge test -vvFR-05, FR-08: post, revoke, claimId stability, commit revert-on-duplicate, latest() after two commits, chain-id 1/137 rejected in script tests.
Fusion mathpytest tests/test_fuse.pyNFR-04: cumulative / averaging operators and revision match the numeric examples in MATH.html within 1e-9 before JSON round-trip.
Schemapytest tests/test_schema.pyFR-02, FR-07: NormalizedClaim and GET body reject unknown fields and wrong polarity.
Modelpython -m services.score.trainFR-03, NFR-03: writes joblib + data/metrics.json with accuracy, F1, Brier. Hold-out 20%. A revoked+expired fixture row must score p < 0.4.
Extractorunit + optional live LLMFR-02: fixture string → valid model. Second test: LLM disabled → rules fallback still passes the inline-JSON fixture.
E2Escripts/demo_flow.shFR-01, FR-04, FR-06, FR-10, NFR-02: posts A+B, waits, curls GET, prints commit latency, exits non-zero if > 120s.
Integritypython scripts/verify_hash.pyFR-09, NFR-05: keccak(preimage) equals on-chain stateHash.
Durabilitykill uvicorn, run replayNFR-07: latest hash unchanged. Overlay file is not the authority.
Loadhey -n 200 -c 20 on GET identityNFR-01: p95 < 500 ms, warm cache, no LLM on the path.
Healthcurl /v1/healthBoth heads, modelLoaded, modelAccuracy, degraded flag. RPC errors must appear, not be swallowed.

Label function for the synthetic set is documented in the train-script header. Do not make revoked=1 ⇒ label=0 the only rule. Include issuer fraud, near-expiry, and opposite-polarity pairs so the accuracy number is not a toy.
